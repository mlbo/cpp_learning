# C++ 35 天系统学习教程

这套教程面向零基础学习者，按 35 天逐层组织基础语法、现代 C++、数据结构与算法、Effective Modern C++、并发编程和综合项目。

[查看 GitHub 源码](https://github.com/mlbo/cpp_learning) · [文档构建说明](https://github.com/mlbo/cpp_learning/blob/master/docs/README.md)

```{admonition} 推荐学习方式
:class: tip
先阅读基础教程补齐编译、变量、控制流、函数、容器、引用和类，再从 Week 1 开始。每天依次完成概念、示例、算法题、工程动作和五句复盘；遇到较难主题可以把一天拆成两次学习。
```
