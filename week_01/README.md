## 本阶段必须建立的四个思维模型

### 1. 半开区间 `[begin, end)`

标准容器和算法普遍使用半开区间。它能自然表示空区间，且区间长度为 `end - begin`。二分、滑动窗口和迭代器都依赖这个模型。

### 2. 循环不变量

不要只背模板。每轮循环前都要能说清：“哪些元素已经处理完？答案目前对哪一段成立？”

### 3. 类型是接口的一部分

`auto` 不是“没有类型”，而是让编译器根据初始化表达式推导具体类型。引用、顶层 `const`、数组退化等规则会影响程序行为。

### 4. 边界优先于技巧

每道题先检查：空输入、单元素、重复元素、目标不存在、整数范围和下标是否越界。

## 本周面试高频问题汇总

把本周的类型推导、空指针、编译期常量、初始化、数组与 vector、二分和双指针串成问答。

### 类型推导与空指针

```
Q1: auto 推导和模板类型推导有什么区别？
A: 几乎一样，但 auto 还能用于变量声明、返回类型和结构化绑定。
   细微差别：用拷贝列表初始化（`auto x = {1,2,3}`）时 auto 推成 std::initializer_list；
   而直接列表初始化（`auto x{1}`）在 C++14 起推成 int、多元素直接列表（`auto x{1,2}`）则报错。
   模板推导则把 {1,2,3} 当成非推导语境而报错。

Q2: decltype 和 auto 的区别？
A: auto 通常按值推导（丢顶层 const 和引用）；decltype 保留 const 与引用，
   并对名字表达式（带括号的表达式）保留引用性。
   简记：auto 是"按值"，decltype 是"原样"。

Q3: nullptr 相比 NULL 解决了什么问题？
A: NULL 在 C 里是 (void*)0，在 C++ 里是整数 0（具体宏定义依实现，可能是 0、`((void*)0)` 或 `__null`）；
   重载 f(int) 与 f(char*) 时 f(NULL) 的选择是**实现相关**的——可能匹配 f(int)、可能歧义、
   可能选错，这正是著名坑。nullptr 是 std::nullptr_t 类型的右值，能正确匹配指针重载，
   也支持模板推导（不会误推成 int）。
```

### 编译期常量与初始化

```
Q4: constexpr 和 const 的区别？
A: const 只表示"不修改"，运行期或编译期都可能；
   constexpr 表示"可在编译期求值"，一定也具备 const 语义。
   constexpr 变量一定是编译期常量；const 变量未必（如运行期传入的值）。
   constexpr 函数在编译期或运行期都可调用，取决于实参。

Q5: {} 初始化和 = 初始化的区别？
A: {} 是统一初始化，禁止窄化（int x{3.14} 报错），
   还能调用 initializer_list 构造。
   代价：{} 会优先匹配 initializer_list 构造，可能导致意外重载选择。

Q6: vector 和 array 的区别？
A: array 是固定大小（模板参数 N），无动态扩容；其存储位置随所在对象而定（局部时在栈、
   静态/成员时随所属对象）。
   vector 是动态数组，其元素缓冲区在堆上分配，支持 push_back 扩容；vector 对象本身可
   在栈、静态区或堆，只有内部缓冲区通常用动态分配。
   array 适合编译期已知大小的容器，vector 适合运行期可变大小。
```

### 算法：二分与双指针

```
Q7: 二分查找的边界为什么容易写错？
A: 区间定义不一致：左闭右闭 [l,r] 与左闭右开 [l,r) 的更新和终止条件不同。
   闭区间写 l<=r、r=mid-1；左闭右开写 l<r、r=mid。
   先定区间语义，再写循环条件和更新，是避免边界 bug 的关键。

Q8: 双指针有哪几种典型用法？
A: 三类：对撞指针（左右相向，如容器盛水）、快慢指针（同向，如去重、找环）、
   滑动窗口（同向、维护满足条件的子段，如无重复最长子串）。
   判断用哪种，看问题是否需要"两端往中间缩"还是"一端追赶另一端"。

Q9: 滑动窗口和双指针有什么关系？
A: 滑动窗口是双指针的一种：左右指针同向移动，维护满足某条件的子区间。
   窗口右扩找可行解，左缩到再次满足条件，从而把 O(n^2) 暴力优化到 O(n)。
```
