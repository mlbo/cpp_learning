# LeetCode 167. 两数之和 II - 输入有序数组

## 题目描述

给定一个**已排序**的整数数组，找出两个数使它们的和等于目标值。

返回它们的下标（从1开始）。

## 解题思路

### 双指针法

利用数组已排序的特性，用两个指针从两端向中间收敛：

```mermaid
sequenceDiagram
    participant 左指针
    participant 数组
    participant 右指针
    左指针->>数组: 指向最小值
    右指针->>数组: 指向最大值
    数组->>左指针: 和<target则右移
    数组->>右指针: 和>target则左移
    数组->>数组: 和=target则返回
```

### 为什么双指针正确？

- 数组有序：小的数在左，大的数在右
- 和 < target：需要更大的数，左指针右移
- 和 > target：需要更小的数，右指针左移
- 在两个下标仍不同时，每次移动都会缩小候选范围；排除证明保证不漏掉由两个不同元素组成的答案

实现使用半开候选区间 `[left, right)`，真正的右下标是 `right - 1`。循环条件要求 `right - left >= 2`，也就是区间里至少还有两个候选元素；这条条件同时覆盖空数组、单元素和指针收敛，避免把同一下标使用两次。两数之和先提升到 `int64_t`，返回 1-based `int` 下标前再检查范围；这使极端整数和超大输入的失败方式明确，而不是依赖溢出或窄化结果。

## 复杂度

| 方法 | 时间复杂度 | 空间复杂度 |
|------|----------|----------|
| 双指针 | O(n) | O(1) |
| 二分查找 | O(n log n) | O(1) |
